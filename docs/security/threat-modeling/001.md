1. ¿En qué estamos trabajando?
En la migración del modulo productos hacia un microservicio, el primer endpoint 
que se va a migrar será /api/v1/products/{1}

2. ¿Qué puede salir mal?
No autorizar nuestro endpoint, sin autorización cualquier persona que tenga la url podrá consultar nuestro endpoint.
No validar el parametro {id}, sin la validación de ese parametro el usuario enviará cualquier cosa y nuestra API no validará el tipo de dato.
